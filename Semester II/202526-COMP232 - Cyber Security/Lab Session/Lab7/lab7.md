简单来说，这个实验是要带你玩转**哈希碰撞（Hash Collision）**。

MD5 曾经被广泛用于校验文件的完整性（就像文件的“指纹”），但现在它已经被证明是不安全的。这个实验就是让你亲手通过“伪造指纹”，让两个完全不同的程序看起来一模一样。

以下是具体的四个阶段：

------

### 第一步：基础碰撞（生成两个不同的二进制文件）

你要使用一个叫 `md5collgen` 的工具。你给它一个初始文件（Prefix），它会通过复杂的数学计算，生成两个各增加了 128 字节数据的文件。

- **结果**：这两个文件内容不同，但它们的 MD5 值会神奇地完全一致。
- **工具**：命令行输入 `md5collgen -p prefix.txt -o out1.bin out2.bin`。

### 第二步：后缀属性验证

验证 MD5 的一个物理特性：**如果 A 和 B 碰撞（哈希相等），那么在它们后面拼接相同的后缀 T，得到的 (A + T) 和 (B + T) 依然碰撞。**

- **操作**：用 `cat` 命令把同一个文件拼在刚才生成的两个二进制文件后面，然后检查哈希值。

### 第三步：欺骗可执行程序（重点）

你要写一个简单的 C 程序，里面定义一个 200 字节的数组（比如装满字符 'A'）。

1. 编译成二进制文件。
2. 找到数组在二进制文件里的起始位置。
3. 把这个位置之前的代码作为“前缀”，用工具生成两组不同的碰撞数据填入数组。

- **效果**：你会得到两个程序，运行后一个打印 A 内容，一个打印 B 内容，但它们的 MD5 码是一样的。

### 第四步：进阶攻击（良性 vs 恶意）

这是最硬核的部分。你要构造一个逻辑判断：

- `if (ArrayA == ArrayB) { 执行正常功能; } else { 执行恶意代码; }`
- 通过修改二进制数据，让第一个程序的两个数组**完全相同**（走正常逻辑），让第二个程序的两个数组**不同**（走恶意逻辑）。
- **终极目标**：由于 MD5 相同，你可以把“良性版”送去安全审查，通过后再发布“恶意版”，而用户手中的安全检测工具会因为哈希值一致而认为它是安全的。

------

### 实验准备建议

1. **环境**：必须在学校提供的 Ubuntu 20.04 虚拟机里做，因为工具 `md5collgen` 和十六进制编辑器 `bless` 已经装好了。
2. **核心工具**：
   - `md5sum`：查指纹。
   - `diff`：比对文件内容。
   - `bless`：像黑客一样直接修改 0 和 1。
