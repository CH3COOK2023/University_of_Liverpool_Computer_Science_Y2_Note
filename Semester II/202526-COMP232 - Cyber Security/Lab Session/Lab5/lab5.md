

### 1. 准备工作

* 
**Java 用户**：下载并运行 `RandomKeyRSAExample.java`（RSA 加解密）和 `MessageDigestExample.java`（SHA-1 散列）。


* 
**Python 用户**：下载并运行 `RSA.py` 和 `HASH.py`（SHA-256 散列） 。


* 阅读代码，理解加密和散列（Hashing）是如何实现的 。



### 2. 核心任务：实现消息认证协议 (Variant b)

你需要编写一个程序，模拟 **发送方 (Sender)** 和 **验证方 (Verifier)** 之间的交互 ：

**发送方 (Sender)**：

1. 输入一段文本消息，用 **SHA-1** 计算其散列值（Digest）。


2. 生成一对 **RSA 公钥和私钥** 。


3. 用**私钥**加密该散列值 。


4. 将“原始消息”、“加密后的散列值”和“公钥”传给验证方 。



**验证方 (Verifier)**：

1. 接收上述内容，通过程序验证消息的真实性 。


2. 你需要通过实验证明，该程序能检测出以下攻击 ：


* 消息在传输中被篡改 。


* 加密后的散列值在传输中被篡改 。


* 两者都被篡改 。

### 3. 使用数字签名算法 (DSA)

* 使用 JCA 或 Python 中现成的 **DSA (Digital Signature Algorithm)** 接口来实现消息认证 。
